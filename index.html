Privacy & Security

🔐 Data Storage

All data is stored exclusively in your browser's localStorage. Nothing is sent to any server. Your resumes, jobs, and API keys never leave your device.

🔑 API Keys

API keys are stored locally with basic encoding. They are used only to make direct requests to AI providers on your behalf. We never proxy or log your requests.

🌐 Network Requests

The app makes requests only to AI provider APIs you configure (OpenAI, Anthropic, etc.) and to Google Fonts for typography. No analytics or tracking beyond anonymous Umami stats.

🗑 Your Rights

You can delete all stored data at any time.
